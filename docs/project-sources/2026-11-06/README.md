# Preserved AskJamie project sources

This library holds the original files requested for repository storage from the shared AskJamie and Professional Portfolio project libraries. The Foundry source tab was empty at capture. The 16 shared-project documents matched 16 of the 23 portfolio-project files byte-for-byte, for 39 observed occurrences and 23 distinct originals. The public tree retains 21 originals representing 35 of those occurrences. Two originals are excluded from the current public inventory pending review and remain in owner custody.

The image-source register additionally preserves 13 observed artwork occurrences as 11 distinct PNGs, including the earlier website comparison, seven GPT-icon candidates, two source components and the owner-supplied final composition. Two component occurrences match earlier candidates exactly.

Files use short ASCII storage names. [manifest.json](manifest.json) retains original document filenames, source roles, dimensions where relevant, byte counts, SHA-256 and Git blob identities. Original bytes and embedded notices are unchanged.

## Use during conversion

Treat these as historical research and design inputs. Recheck dated platform claims and source citations when turning them into current instructions. Keep raw conversations, candidate dossiers and personal voice evidence in the private source register. The existing capability owners retain integration and host acceptance.

- Shared methods: instruction structure, knowledge preparation, prompt equilibrium, semantic interference, modular manufacturing and agent coordination.
- AJ01: apply the shared methods to evidence-grounded representative behavior and its private approved candidate sources.
- AJ02: apply the shared methods to supported service/capability descriptions, brand communication and business portfolio evidence.
