# Capability subtrees

This is the destination namespace for reviewed public AskJamie capabilities.

AJ01 and AJ02 now have owner-approved public child metadata scaffolds:

- [Resume Representative](askjamie-aj01-resume-representative/README.md)
- [Professional Portfolio](askjamie-aj02-professional-portfolio/README.md)

Their file indexes preserve source identities, not original file bytes. Source
imports, portable skills, host acceptance and retirement remain pending. Follow
the [staged migration plan](../docs/migrations/aj01-aj02-2026-10-19.md).

Use `capabilities/<existing-capability-slug>/` with the canonical `_template/`
layout, portable products in `skills/` and target adapters in `adapters/`.
Consult [the migration contract](../docs/skill-first-foundry.md) and
[registry migration records](../registry/index.yaml).

Private capability material belongs outside this public checkout. A directory
is not an access boundary. Every permanent-private entry remains protected.
