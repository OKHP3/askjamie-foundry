## Repository contract (BrandGuard™ rules)
- **Public-only materials:** Do not store confidential, internal, proprietary, or private information here.
- **Brand-safe routing:** When a user needs authoritative details or real-world action, route them to official LVMH channels.
- **Human blessing principle:** Avoid automation that replaces explicit human approval in luxury-sensitive decisions.

## Structure
- `/prompts/` — instruction spine, tone, guardrails, examples  
- `/src/` — source corpus (public references, notes, transcripts, drafts)  
- `/build/` — compiled packs for upload (Knowledge + Project-friendly)  
- `/eval/` — regression prompts + rubrics  
- `/ops/` — release checklist, workflows, governance  
- `/web/` — lens page assets / publishable web artifacts  
- `gpt_manifest.yaml` — crosslinks + version metadata (single source of truth for wiring)

## Update workflow (quick)
1. Update prompt + corpus in `/prompts` and `/src`.
2. Rebuild packs into `/build` (keep the number of upload files low by bundling).
3. Upload refreshed packs to:
   - the **Custom GPT** (Knowledge)
   - the **ChatGPT Project** (Workbench)
4. Update changelog + lens page artifacts as needed.
