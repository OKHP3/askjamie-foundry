# BRG07 knowledge packs

This directory contains public-source knowledge packs for GPT-BRG07, the LVMH lens in the OKHP3 BrandGuard system.

The current inventory covers 17 topic families. Each family has DOCX and PDF files under the `v01a` and `v01d` version labels. Topics include LVMH history, mission and brand philosophy, products, consumers, financials, sustainability, innovation, partnerships, marketing, customer experience, risks, competitive positioning, media coverage, future trends, product comparison, FAQs, and reputational liabilities.

Keep materials public-only. These packs support reference and analysis workflows; they do not replace current information from official LVMH sources.
