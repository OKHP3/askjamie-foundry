## Operating rules (hybrid method)
- GitHub is the **source of truth**. Notion is the **planning/decision log**. ChatGPT Project is the **workbench**. Custom GPT is the **product surface**.
- Store unlimited raw materials in /knowledge (and related folders), but publish **compiled packs** in /build to stay within platform upload limits.
- Keep content public-source and citation-friendly; write in a way that can be safely routed back to official channels.
- Treat the revision map in `/knowledge/INDEX.md` as the working publication guide until a formal release process replaces it.
