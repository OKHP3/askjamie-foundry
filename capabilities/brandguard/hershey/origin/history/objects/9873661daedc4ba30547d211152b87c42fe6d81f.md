## What lives here
- **Prompts**: instruction spine, tone, guardrails, examples
- **Corpus (public-only)**: curated Hershey-facing knowledge used to ground outputs
- **Build artifacts**: compiled “packs” intended for upload to the Custom GPT / Project
- **Eval harness**: regression prompts + rubrics + expected behavior notes
- **Ops**: release checklist, version notes, decision log excerpts

## Suggested repo layout
```text
/prompts        # system prompt, style rules, guardrails, few-shots
/src/corpus     # raw public-source notes (markdown preferred)
/build          # compiled packs (knowledge-pack.md, prompt-pack.md, eval-pack.md)

gpt_manifest.yaml
CHANGELOG.md
````

## Operating rules (BrandGuard stance)

* **Public sources only.**
* **No guessing, no internal claims, no “insider” tone.**
* When real-world action or official policy matters, **route users to Hershey’s official channels**: [https://www.thehersheycompany.com](https://www.thehersheycompany.com)
* Keep messaging consistent with the BrandGuard lens: protect identity, framing, and accuracy.

## Update workflow (hybrid method)

1. Update `/src/corpus` and `/prompts`
2. Rebuild `/build/*-pack.md`
3. Upload refreshed packs to:

   * the **Custom GPT** (Knowledge)
   * the **ChatGPT Project** (Workbench files)
4. Update the canonical web hub if needed
5. Record changes in `CHANGELOG.md` and bump version in `gpt_manifest.yaml`
