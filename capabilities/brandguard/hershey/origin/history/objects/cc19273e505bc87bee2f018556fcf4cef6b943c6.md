# OKHP³ BrandGuard™ — Hershey (BRG06)

An AI brand compliance monitor repository. This project stores and manages resources for a Custom GPT (OpenAI/ChatGPT) designed to monitor and enforce Hershey brand standards.

## Project Structure

- `/prompts` — System prompts and instruction sets for the GPT
- `/knowledge` — Core RAG source files (PDFs/DOCXs) for brand knowledge
- `/src/corpus` — Public-source corpus and RAG packs
- `/eval` — Evaluation tests and benchmarks
- `/ops` — Operations and deployment configurations
- `/build` — Compiled resources and build artifacts
- `/releases` — Release notes and versioned history
- `/docs` — Project documentation
- `gpt_manifest.yaml` — Central metadata defining the GPT's identity and repo structure

## Tech Stack

- **Type**: Documentation / AI asset repository (no web server or build system)
- **Languages**: Markdown, YAML, PDF, DOCX
- **Platform**: Custom GPT (OpenAI)
- **Environment**: Nix (stable-25_05)
