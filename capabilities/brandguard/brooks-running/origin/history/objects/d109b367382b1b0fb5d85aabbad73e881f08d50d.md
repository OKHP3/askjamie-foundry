## Update Workflow (Hybrid Method)
1. Add/refresh public sources in `/src/`
2. Update prompt architecture in `/prompts/`
3. Rebuild packs into `/build/` (e.g., `knowledge-pack.md`, `prompt-pack.md`, `eval-pack.md`)
4. Run eval prompts in `/eval/` and record outcomes
5. Update `CHANGELOG.md` + bump version in `gpt_manifest.yaml`
6. Sync the latest packs into:
   - **Custom GPT Knowledge** (stable “golden set”)
   - **ChatGPT Project files** (Workbench context)
