## Update policy

- Dependabot runs weekly for Python dependencies and GitHub Actions.
- The scheduled technology check compares the declared PyYAML version and Replit's Nix channel with current stable release information.
- Pull requests must pass the repository's structural checks and any newly introduced validation before merging.
- Major runtime or Nix channel changes require human review because this repository has no application test suite yet.
