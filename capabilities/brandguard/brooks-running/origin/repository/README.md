# AskJamie-GPT-BRG03

Partial knowledge-pack foundation for GPT-BRG03, an AskJamie BrandGuard concept for Brooks Running.

The repository currently contains public-source research artifacts, 17 topic families of Brooks Running knowledge packs in DOCX and PDF formats, repository-local Agent Skills, and technology-maintenance documentation. It does not currently contain an application runtime, retrieval pipeline, evaluator, build process, or deployment proof.

## Start here

- `AGENTS.md`: repository boundaries, evidence rules, and validation commands
- `gpt_manifest.yaml`: project metadata and intended artifact areas
- `knowledge/`: Brooks Running topic packs and revision variants
- `.agents/skills/`: repository-local Agent Skills and their resources
- `docs/TECHNOLOGY-INVENTORY.md`: declared technology and maintenance workflow

## Knowledge-pack status

Most topics have `v01a` and `v01d` DOCX/PDF variants. `KNOW10` also has `v02d`. The repository does not yet document a canonical revision-selection rule, so these files must not be silently merged or deleted.

The packs are reference material compiled from public sources. Their dates and citations do not make time-sensitive claims automatically current or establish Brooks Running endorsement.

## Scope boundary

The manifest and external links describe intended metadata only. They do not prove that a Custom GPT, web application, retrieval integration, or deployment is active.
