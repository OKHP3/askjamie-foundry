## Verifying the selections

The [provenance manifest](provenance.json) records each original Git blob, its SHA-256, the selection, and the SHA-256 of the resulting file. Markdown passages preserve the source line bytes. Visible dividers identify gaps, and HTML comments identify the one-based inclusive source line ranges. The JSON selections retain original field values and array order. The research-lead indices in the manifest start at zero.

The [source snapshot](../source.json) counts only complete original files. These selections have separate paths and checksums. The 16 original dossiers in Markdown, Word, and PDF and the original research reconciliation workbook and research leads file still require the source for byte-for-byte recovery. The [historical version index](../history/README.md) covers all 195 versions outside the pinned default tree.
