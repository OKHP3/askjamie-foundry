# AskJamie-GPT-BRG09

Storage and release support for GPT-BRG09, OKHP3 BrandGuard for Coca-Cola.

This is a content-first repository. Its populated source material is the
`knowledge/` library: 17 Coca-Cola topic areas, each retained as paired DOCX
and PDF exports in two tracked version families, `v01a` and `v01d`. The two
families are materially different and must not be treated as duplicates until
the owner records the intended canonical retrieval set.

The repository also contains local Agent Skills under `.agents/skills/`,
repository metadata, and a small technology-maintenance utility. Prompt,
evaluation, build, release, site, and application areas are reserved for
future work and are not implemented runtimes in this checkout.

## Start here

- `AGENTS.md`: repository operating rules and evidence boundaries.
- `gpt_manifest.yaml`: intended GPT identity, structure, links, and disclaimer.
- `knowledge/`: paired Coca-Cola research exports.
- `.agents/skills/README.md`: generated inventory of local Agent Skills.
- `docs/technology-inventory.md`: recorded tooling and explicit non-runtime
  boundaries.

## Status and boundaries

Status: content and release repository in development. No running application,
