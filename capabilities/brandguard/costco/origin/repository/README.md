# AskJamie-GPT-BRG05

Repository for GPT-BRG05: Costco - OKHP3 BrandGuard. Stores prompts, versioned knowledge packs, evaluation assets, and site support files for the Costco lens.

This repository is currently content-seeded and implementation-incomplete. The checked-in knowledge corpus is the primary populated project area. Future prompt, evaluation, build, operations, and publication areas are described in the manifest but are not created until they contain real project material.

The repository also contains local Agent Skill support under `.agents/`. The root `skills/` folder is limited to reviewed publication mirrors generated from those local skill sources; it is not Costco product content or application runtime code.
