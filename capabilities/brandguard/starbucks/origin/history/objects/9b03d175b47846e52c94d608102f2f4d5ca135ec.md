# GPT-BRG02: OKHP³ BrandGuard™ — Starbucks

## Project Overview

This is a **content and version-control repository** for GPT-BRG02: OKHP³ BrandGuard™ — Starbucks. It stores prompts, knowledge packs (RAG-ready), evaluation tests, and supporting artifacts for a Custom GPT AI brand compliance monitor.

There is **no runnable application** — no frontend, backend, or build process. The repository is organized as follows:

- `/knowledge/` — Core knowledge base (PDF, DOCX) for RAG
- `/prompts/` — Instruction blocks, tone/behavior rules, guardrails, few-shot examples
- `/src/` — Source corpus, notes, drafts, and references
- `/eval/` — Evaluation tests and rubrics
- `/build/` — Compiled knowledge-packs and prompt-packs ready for upload to Custom GPT
- `/ops/` — Operational files and scripts
- `/docs/` — Supporting documentation, policies, diagrams
- `gpt_manifest.yaml` — Project metadata, versioning, and directory mapping
