# GPT-BRG02: OKHP³ BrandGuard™ — Starbucks

## Project Overview

This is a **content and version-control repository** for GPT-BRG02: OKHP³ BrandGuard™ — Starbucks. It stores Starbucks knowledge packs and planned prompt, evaluation, and release artifacts for an intended Custom GPT brand-compliance monitor.

There is **no runnable application** — no frontend, backend, or build process. The repository is organized as follows:

- `/knowledge/` — Core knowledge base (PDF, DOCX) for RAG
- `/prompts/` — Planned instruction blocks, tone/behavior rules, guardrails, and few-shot examples; currently empty
- `/src/` — Planned source corpus; currently empty
- `/eval/` — Planned evaluation tests and rubrics; currently empty
- `/build/` — Planned compiled knowledge and prompt packs; currently empty
- `/ops/` — Operational files and scripts
- `/docs/` — Supporting documentation, policies, diagrams
- `gpt_manifest.yaml` — Project metadata, versioning, and directory mapping
