# AskJamie-GPT-BRG11

Source material for GPT-BRG11: Scheels, an OKHP³ BrandGuard knowledge foundation.

Current repository contents:

- `knowledge/`: 17 paired Scheels knowledge packs in DOCX and PDF formats.
- `docs/`: technology inventory and repository notes.
- `ops/`: maintenance utility used by the technology-drift workflow.
- `.agents/`: repository-local skills and supporting evaluation material.
- `skills/`: the intentional publication mirror for the skill-promotion package.

Prompt, evaluation, retrieval, application, site, and release surfaces are not currently populated. They will be added only when they contain real project material. The repository is public-source focused and routes users to official SCHEELS information at [scheels.com](https://www.scheels.com/).
