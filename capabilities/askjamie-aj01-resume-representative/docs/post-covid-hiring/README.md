## Reproduce the PDF

Run the included renderer with Python, ReportLab and a local Arial font directory containing the four regular, bold, italic and bold-italic TTF files. The fonts are supplied by the environment.

```text
python render-pdf.py --font-dir /path/to/fonts --output rebuilt.pdf
```
