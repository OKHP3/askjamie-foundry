and portfolio disclosure. The same private evidence can support a résumé
through Resume Representative and an individual case study through Career
Portfolio Curation. Each draft has its own evidence and review state.

## Standalone starter kit

Distribute one extractable archive with a start guide, source intake and
workflow guides, portable skills, a folder map, an inventory template, a
fictional example, a setup helper, and a manifest. Keep the extracted methods
separate from the private workspace they help initialize.

Organize the private workspace by purpose. Keep career strategy and the
evidence canon apart from job search and work-search activity. Keep employer
records, education and credentials, and LinkedIn exports in their respective
source lanes. Preserve historical résumé sources and restricted references
separately from broad résumé masters and role-specific variants.

Use an existing opening record when its employer and exact posting or
requisition match. Create a new opening subfolder when there is a concrete
opening and material to file. Link corresponding work-search entries and
résumé versions without treating an activity or draft as an application
receipt. The [career workflow skill map](career-workflow-skills.md) routes
those operations to their respective skills.

For first run, preview the directories under the owner-selected private root.
With approval, initialize a new or empty workspace and verify the resulting
paths. Preserve existing files and refuse unsafe destinations or populated
roots. Start a private source inventory while any account export is pending.
Keep originals private and admit only the approved professional subset.

## Optional local setup wizard

A future archive can include a browser-based start screen, local interface
assets, and a small launcher. The screen can guide the owner through selecting
a private location, previewing the folder plan, and collecting sources. The
owner can read the guides directly after extraction. If folder creation is
requested, a local helper can apply the approved plan and report what it
verified. Keep account export requests owner-operated and private source data
local. Browser installation, cross-platform execution, and host activation
are separate acceptance checks for a future implementation.
