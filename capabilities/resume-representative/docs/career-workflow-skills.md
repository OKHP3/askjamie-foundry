## What makes these skills

Each selected workflow has a recurring trigger, bounded inputs, decisions that
general advice does not resolve, a verifiable output and a safe blocked state.
The reusable asset is the decision contract and evidence model, not a transcript
dump, a directory tree or a personal resume.

## Architecture and gaps addressed

The two new packages target Agent Skills-compatible clients and can run from
supplied snapshots. Connected sources are optional and their availability must
be checked. There is no automatic browser, Notion, OneDrive or mail connector.

Work Search Evidence accepts actual activity evidence and program instructions,
and produces a private ledger, unresolved queue and period review. Its knowledge
advantage is separation of event/receipt/observation dates, exact opening and
attempt identities, duplicate receipts, uncertain attendance, per-event counting
decisions, and guarded writes. It does not determine benefits entitlement.

Career Artifact Audit accepts approved root mappings and baseline references,
and produces a scoped inventory, exact-reference map and preservation findings.
Its knowledge advantage is cross-layer identity, overlapping roots, Unicode
collisions, stale search indexes, empty replacement folders, incomparable hashes
and precise runtime blockers. It does not execute cleanup or recovery.
The existing file-routing skill decides where new material belongs and can file
it when authorized. This audit tests existing artifacts and legacy references
against a scoped baseline, producing preservation findings and proposed maps.
Workspace intake identifies operating owners and surfaces; it does not perform
this item-level preservation audit. These boundaries avoid a second filing or
workspace coordinator.

The source conversation exposed missing reusable contracts: stable identities,
provenance clocks, explicit coverage, partial completion, write guards, separate
local/cloud verification, privacy filtering, portable destinations and regression
cases. The initial packages turn those gaps into procedure and templates.

## Canonical home and composition

Publish source in this existing Resume Representative capability. The owner
explicitly selected this repository as an acceptable destination. No new child
repository, registry identity, visibility change or private source import is
needed. This is a source package release, not a web deployment or installed host.

Skillz supplies the authoring and review standards and existing social workflows.
Do not put unemployment evidence or storage audit under social-posting. A later
Skillz mirror should use an explicit canonical/mirror manifest and exact hashes;
this release does not claim that such a mirror or local installation exists.

Use these workflows in sequence when needed: triage -> source-grounded tailoring
-> separately authorized application work -> status reconciliation -> actual
work-search evidence. Run artifact audit independently when references or
preservation are uncertain. An application receipt can inform both status and a
linked activity record, but does not create several activities.
