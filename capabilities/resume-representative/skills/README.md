# Resume Representative skills

## Career activity companions

- Use [LinkedIn DM Reconciliation](okhp3-linkedin-dm-reconcile/SKILL.md)
  to reconcile notification emails with actual incoming and outgoing platform
  messages before assigning an unanswered request or next-action owner.

- Use [Activity Reconciliation 0.1.0](https://github.com/OKHP3/skillz/tree/34a990fba6c92676928858b8b369c2cd1a3137ac/knowledge-operations/okhp3-activity-reconciliation)
  to review existing follow-ups against Sent Items or refresh a bounded
  activity log from supplied or authorized evidence. The package can also
  guide separately authorized filing of minimal evidence by position.
- Use [Application Status Reconciliation](okhp3-application-status-reconciliation/SKILL.md)
  for exact applications, employer and portal dispositions, and authorized
  corrections to application records.

The activity package is maintained in Skillz. It is a draftable companion for
supervised use. This reference provides the pinned source for separate
installation on a compatible client. Source access, destination permissions,
and user authorization are checked at runtime.

## Professional portrait companions

- Use [Professional Headshot 0.1.0](https://github.com/OKHP3/skillz/tree/9e729371db1901842fae839a12e7dd1146711abd/askjamie/okhp3-professional-headshot)
  to create or refine a realistic, recognizable career portrait from supplied
  or explicitly authorized photos. The package defines reference roles, current
  likeness, expression-only revisions, visual review, and verified delivery.
- Use [Guided Photo Session 0.1.0](https://github.com/OKHP3/skillz/tree/9e729371db1901842fae839a12e7dd1146711abd/universal/okhp3-guided-photo-session)
  when new stills are needed. It requires verified capture controls, current
  readiness, user-visible stop and relax cues, bounded posing, and separate
  saved, verified, and delivered counts. Camo guidance is an optional adapter.

These are canonical Skillz packages, pinned here for separate installation on a
compatible client. They are draftable with analytical review only. The synthetic
cases are author-visible; live image/camera evaluation and a protected holdout
remain open. Portrait image work needs an available editing tool. Live capture
needs authorized usable controls and communication, otherwise it returns a
user-operated workflow. Neither reference grants photo search, account upload,
public publication, persistent camera access, or destructive file migration.
