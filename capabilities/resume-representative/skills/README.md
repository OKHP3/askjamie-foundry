# Resume Representative skills

## Career activity companions

- Use [LinkedIn DM Reconciliation](okhp3-linkedin-dm-reconcile/SKILL.md)
  to reconcile notification emails with actual incoming and outgoing platform
  messages before assigning an unanswered request or next-action owner.

- Use [Activity Reconciliation 0.1.0](https://github.com/OKHP3/skillz/tree/34a990fba6c92676928858b8b369c2cd1a3137ac/knowledge-operations/okhp3-activity-reconciliation)
  to review existing follow-ups against Sent Items or refresh a bounded
  activity log from supplied or authorized evidence. The package can also
  guide separately authorized filing of minimal evidence by position.
- Use [Application Status Reconciliation](okhp3-application-status-reconciliation/SKILL.md)
  for exact applications, employer and portal dispositions, and authorized
  corrections to application records.

The activity package is maintained in Skillz. It is a draftable companion for
supervised use. This reference provides the pinned source for separate
installation on a compatible client. Source access, destination permissions,
and user authorization are checked at runtime.
