# Intake record

Use a stable source ID such as `S-04` within one subject's workspace. Track an
authorized source even when it is pending, unreadable, or excluded. For
excluded material record only safe category and reason when the owner authorizes
retaining that fact.

| Field | Record |
|---|---|
| Source ID and subject | Stable ID and internal subject key |
| Class and purpose | Historical résumé, profile export, employment record, education, credential, project artifact, target posting, or restricted material |
| Locator and lineage | Private source location and segment if known, verified digest when available, exact-duplicate locators, and any known derivation or version relation |
| Dates | Capture date and basis, event or coverage period when supplied, and archive request, ready, and download events where relevant |
| Access | Readable, pending, unreadable, or excluded, with reason and reviewed subset |
| Permitted use | Approved scope for inspection and private drafting. Track disclosure rights separately. Default unresolved rights to private handling. |

Keep historical work and current target requirements in distinct lanes. Retain
only the minimum context necessary. For an unsupported file format or unsafe
archive, request a plain-text, redacted excerpt or other safe subset from the
owner. For LinkedIn, use the current account-data procedure and the actual
readiness notification. [LinkedIn Help](https://www.linkedin.com/help/linkedin/answer/a1339364/downloading-your-account-data)
