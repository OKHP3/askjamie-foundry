# Referral follow-up

An integration candidate for a specific contact and one or more job openings.
It distinguishes the outgoing request, subsequent reply, an actual introduction,
and a confirmed formal referral. It can produce a draft with supplied evidence;
platform access and record mutation are separate host capabilities.

## Synthetic example

A candidate previously sent a contact two role IDs and asks for a follow-up.
The contact earlier offered to help but did not confirm a referral. Draft a
message that asks for an update without claiming delivery or a hiring decision.
If the candidate asks to see it first, stop at the draft. After a separately
authorized send, verify the exact message and update only matching records via
a safe write route; note any blocked mirror.

## Evidence and limits

The included cases are visible development designs. A live matched benchmark,
native activation test, and unseen external holdout are not recorded. Structural
validation and analytical review do not establish performance or host readiness.
