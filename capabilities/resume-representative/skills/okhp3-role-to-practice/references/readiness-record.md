# Role readiness record

Use one record per exact opening and a summary across openings. Keep citations
with the facts they establish. Write `unknown` where a needed fact is
unavailable. Keep candidate-specific records within the authorized audience.

| Section | Record |
| --- | --- |
| Opening | Employer, requisition or provisional posting ID, location variant, source URL and observation date, exact or unresolved identity |
| Candidate constraints | Stated geographic, travel, work-mode, pay or time constraints, with source and unknowns |
| Requirement map | Posting excerpt and source, required/preferred/ramp-up/unclear, candidate evidence and ownership, consequence, verification needed |
| Priority | Fits/stretch/hold/provisional, rationale tied to material requirements and constraints, what would change the decision |
| Learning | Specific gap, official item ID or URL, content type, prerequisites, expected time if published, account observation and date |
| Practice | Scenario, stage, actor roles, expected results, tests run, evidence and remaining limitations |
| Next action | One next step, owner and blocking question or source |

A hard requirement outside the candidate's constraints can warrant a hold even
when the rest fits. A preference or ramp-up expectation can warrant a targeted
exercise. Prefer a qualitative ranking with a reason for ties or uncertainty.

## Keep learning and practice states separate

- **Learning action:** recommended, opened, requested start, or attempted with
  unverified result. Name the exact action and page or item observed.
- **Account learning state:** unknown, not started, in progress, or completed.
  Treat missing access, missing history, and a bare lesson page as insufficient
  to classify persisted progress. Describe ambiguous UI signals in their own
  words. Capture existing progress before reporting a new start.
- **Award:** badge, certification, or none verified. Record an award separately
  from course completion. Verify that the credential name and any relevant
  current standing match the employer requirement.
- **Practice:** planned, built with artifact evidence, or tested with observed
  cases and results. Scope tested claims to the environment and tests run.

Candidate-reported achievements can inform prioritization. Retain attribution.
When a source is stale, inaccessible, or ambiguous, explain which decision is
provisional and what current evidence would resolve it.
