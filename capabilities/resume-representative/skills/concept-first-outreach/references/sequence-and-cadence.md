# Sequence, reply playbook, and cadence

## Contact roles

| Role | Who | First message carries |
|---|---|---|
| Ally | A close, active contact who knows both the candidate and the target | The strategy, both first and second-touch artifacts, a request for critique, and one line asking for discretion |
| Target | The decision maker | The shared-history opener, the concept in a paragraph, and the brief only |
| Mutual | A dormant contact who shares the history | A genuine reconnect, a neutral update, and the outreach mentioned as context; no attachments |

## Message rules without a messaging skill

- Open with something specific and true about the shared history; never
  imply familiarity that does not exist.
- One purpose per message and one low-cost ask.
- Attachments follow the contact-role table above and nothing else.
- Include contact details only when the candidate asks.
- Before returning, scrub for loaded or clinical language, disparagement,
  confidential detail, and unsupported claims.

## Order

1. Ally, then wait for their read or a reasonable interval.
2. Target.
3. Mutuals, after the target message is sent, so any mention is true and the
   target hears it first-hand.

## Checks for every recipient

- **Competitor check.** If a recipient works for an organization the brief
  names as a competitor, send them no artifacts and nothing strategic.
- **Current-role check.** Use the recipient's current profile, not press
  releases, before acknowledging their role.
- **Leakage check.** Read each draft as if it will be forwarded to the target.
  Urgency, desperation, or strategy commentary that would weaken the concept
  stance gets an alternative.

## The direct question

Prepare the answer to "Are you looking?" or "Have you applied?" before the
first send. It should confirm interest plainly, name the role, acknowledge the
title gap in one clause, and offer the deck and résumé, or a conversation.

## Cadence

These are planning defaults drawn from practice, not measured response
rates. Adjust them for the target's calendar and the candidate's deadlines.

| When | Action |
|---|---|
| Reply received | Respond the same day, ideally within hours; offer two specific times |
| About 7 days, no reply | One short nudge with a new, relevant data point; no re-attachment |
| A dated decision point (for example, two to three weeks) | Apply through the formal process if the concept route has stalled; the outreach has still made the name familiar |
| Any posted deadline | Takes priority over the concept route |

## Host note: large files

Some connectors cannot carry large binary files. When that happens, deliver
the file directly to the candidate or write it into a synced local folder they
have connected, then list the destination to confirm it arrived. Do not report
a save that was not verified.
