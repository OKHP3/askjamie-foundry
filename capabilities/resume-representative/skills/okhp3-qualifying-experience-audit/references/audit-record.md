# Qualifying experience audit record

## Counting rules

- Use only phases in which the required work and any coupled qualifiers are
  supported. Establish the actual phase dates. A single observed event does
  not extend to the whole role. Overlapping source descriptions of the same
  work corroborate it without adding tenure.
- If the employer specifies a method, record and apply it at the precision
  the inputs support. A continuous-tenure rule requires one continuous span.
  A full-time-equivalent rule requires evidenced hours and an explicit credit
  formula. If concurrency changes the result, verify how that rule handles
  overlapping hours and any credit cap.
- For the default calendar audit, use start-inclusive, end-exclusive ranges.
  Move an expressly inclusive last day forward one day for calculation. If
  exact boundary semantics are unknown, keep the alternatives when material.
  For imprecise dates, use the latest plausible start and earliest plausible
  end for certain coverage, and the earliest plausible start and latest
  plausible end for possible coverage. Use the corresponding year or month
  boundaries only to compute bounds. Do not convert imprecise source dates
  into exact work-history dates. Cap ongoing intervals at the date through
  which work is supported, preserving that date's precision.
- Union the ranges within each requirement, preserving gaps and counting
  concurrency once. Count complete named months inside the certain coverage
  and the possible coverage. A touched month that is known to be partial
  cannot count as a complete month. For exact dates, show covered days where
  named-month totals could obscure the actual elapsed work. Use 12 months per
  year as a reporting convention. For one exact continuous span and a
  whole-year threshold, also check whether its exclusive end reaches the
  start-date anniversary. State which audit basis supports the decision.
  If an anniversary date is ambiguous or the employer's convention could
  materially change the answer, flag the counting rule for verification.
- When sources give mutually exclusive accounts of one phase, calculate each
  supportable scenario separately. Do not union conflicting alternatives.
  A bound across scenarios must use the lowest certain and highest possible
  totals of those scenarios, with the disagreement visible. If a scenario
  cannot be bounded, record the unknown instead of inventing a maximum.
  These totals cover documented qualifying ranges only. Incomplete history
  can prevent an evidenced shortfall decision.

For example, confirmed design work from January 1, 2016 through December 31,
2020 and July 1, 2019 through December 31, 2022 covers 84 completed calendar
months after removing overlap. If those boundaries were given only by month,
the merged intervals would support 82 certainly complete and 84 possibly
complete calendar months. For January 15, 2023 inclusive through January 15,
2024 exclusive, one full anniversary year is defensible under the exact
continuous-span convention even though only 11 complete named months fit
inside the interval.

## Ledger fields

| Record | Capture |
|---|---|
| Requirement | Exact job identity and wording, source, observation date, required/preferred/unclear, qualifiers, threshold, unit, rule |
| Work phase | Candidate, activity, personal contribution, domain and platform, date range and precision, role concurrency, source IDs |
| Evidence | Source type, attribution, evidence date, access, conflict or limit, shareable pointer if authorized |
| Arithmetic | Included intervals, excluded and unresolved phases with reasons, as-of date, overlap handling, certain/possible totals or employer-rule calculation |
| Judgment | Requirement-level decision, rationale, evidence strength, wording ceiling if useful, next focused question |

Keep one row per work phase when responsibilities change within a job. Keep
candidate recollections attributable. When conflicting sources change the
answer, retain both accounts and ask for the smallest fact that resolves the
conflict. If that fact remains inaccessible, preserve the resulting decision
limit in the handoff.
