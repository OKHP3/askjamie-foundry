## Purpose and scope

The repository packages an Ask Jamie declarative agent for unified information discovery across Microsoft 365 and enterprise systems. The agent instructions describe search, retrieval, summarization, clarification, contextual enrichment, and permission-aware responses for collaboration content, support tickets, knowledge articles, HR information, and related enterprise data.

The repository is an export and packaging project, not a conventional application service. It contains no server, client source tree, connector implementation, database schema, infrastructure, or automated deployment workflow.

Do not infer that the integrations described in the agent instructions are connected or operational. The repository contains no connector configuration or action definitions that prove runtime availability.
