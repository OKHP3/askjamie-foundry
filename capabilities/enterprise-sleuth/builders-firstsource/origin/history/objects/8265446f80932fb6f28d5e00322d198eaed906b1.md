## Version maintenance plan

1. Run `.github/workflows/technology-version-check.yml` weekly and on changes to the inventory or manifests.
2. Treat a failed check as a review signal. It reports drift and links to the authoritative release page.
3. Review Microsoft schema changes manually before editing the manifests. The workflow must not rewrite agent behavior or package files automatically.
4. Let Dependabot update GitHub Action references in the workflow.
5. When a schema upgrade is approved, update both the root manifest and the packaged ZIP export, then run the repository validation checks in `AGENTS.md`.

The repository also contains bundled Agent Skills under `.agents/skills/` and a
publication mirror under `skills/okhp3-skill-promotion/`. These are maintenance
and distribution assets, not proof of an application runtime.
