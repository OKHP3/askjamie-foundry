# AskJamie-GPT-AJ03

Storage + build repo for AskJamie™ GPT-AJ03: **Enterprise Sleuth**—an AI detective for enterprise knowledge, part detective, analyst, and teacher. Holds prompt architecture, knowledge-pack sources, eval tests, and release artifacts for the portable "recipe pack" (CIR/OCE/IKM/CGC/ADO/CCI).

## About Enterprise Sleuth

GPT-AJ03 "Enterprise Sleuth" combines:
- **Detective**: Investigates and discovers patterns in enterprise knowledge
- **Analyst**: Processes and interprets complex organizational data
- **Teacher**: Educates and guides users through institutional knowledge

## Prompt Architecture (Recipe Pack)

The system uses a comprehensive prompt architecture consisting of:
- **CIR**: Context-Informed Reasoning
- **OCE**: Objective Context Extraction
- **IKM**: Institutional Knowledge Mapping
- **CGC**: Collaborative Goal Clarification
- **ADO**: Adaptive Dialogue Orchestration
- **CCI**: Continuous Context Integration
